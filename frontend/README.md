# Beyond the Birth Rate

An interactive story about fertility, income, child survival, and female secondary enrollment across countries. The charts use processed World Bank WDI data from the project notebooks.

From this directory, run `npm install` and `npm run dev` to view the app locally. Run `npm run build` to create a production build. After running the notebooks, run `python backend/export_data.py` from the project root to refresh the chart data.
